# Architecture Decision Records

Each file records **one choice HuginnDB made among alternatives**: what was decided, what it was weighed against, and what follows from it. If you are about to undo one of these, the entry is the argument you have to answer first. If the context it describes has changed, write a new ADR that supersedes it rather than editing the old one. See [the taxonomy](../README.md#three-kinds-of-entry).

*Trap* marks ADRs whose decision was forced by an external trap. Those traps are also listed in the [gotchas index](../gotchas/README.md).

The **Decision** and **Alternatives rejected** lines at the top of each entry were added when these notes were reclassified (2026-10-15). They were distilled from the body that follows them, which is the original record. Where the body named no rejected alternative, the entry says so rather than inventing one.

Template: [`../templates/adr.md`](../templates/adr.md).
