# Conventions

A convention is **a rule for how code is written in this repo**: a folder layout, a dependency rule, a UX doctrine, a checklist. It governs many call sites rather than settling one question, and it changes by agreement, edited in place. A convention that `CONTRIBUTING.md` also states should point there rather than restate it, so the two cannot drift. See [the taxonomy](../README.md#three-kinds-of-entry).
